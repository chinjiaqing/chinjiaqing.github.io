A股量化验证 ​

一句话：一个不预测、不荐股的短线验证体系——拿 2 万元本金级别的小账户视角，把"盘面传言"逐个丢进预注册统计机器里证真或证伪。 这里记录的不是"明天买什么"，而是"哪些路走不通、哪条路还活着"。

这个系列在做什么 ​

市场里 90% 的"短线秘诀"都长这样：先有一个赚钱的故事情节，再找数据硬凑证据。 本系列反着来：先冻结协议 → 再写代码 → 只跑一次不调参 → 如实落盘，允许并预期 NO_EDGE。

目前所有验证线围绕同一个宇宙展开：主板（60/00 开头）涨停板接力/首板生态， 摩擦成本一律扣双边 0.35%，超额收益对标中证 1000（000852）。

为什么值得信：四条统计纪律 ​

  1. 预注册（Pre-registration）：每个假设在跑数据前先写成协议（家族、阈值、裁决规则）， 冻结后不许改。改协议 = 新版本号 + 全量重算。协议文件本身就是要交付的"卷宗"。
  2. cluster bootstrap + BH-FDR：按"事件/日期"聚类重采样（不是按笔数）， 多重检验用 Benjamini-Hochberg 控 FDR，防"10 个桶里挑 1 个显著的"。
  3. n 红线：样本不足 30 不输出结论；报告永远双列 n_events / n_pairs。
  4. 时间胶囊与未来函数防线：已归档事件标题/摘要不可改；行情只取 available_time （盘前→09:30、午间→13:00、盘后→次日 09:30）之后的，杜绝拿"今天的信息"算"昨天的收益"。

执行口径（重要，曾引发认知混乱，已审计钉死） ​

Step 1/4 的收益计算是 A 股 T+1 制度下真实可执行的跨日持仓，不是"当日买当日卖"：

T 日盘中首板确认时以涨停价(Close_T)排单买入 → 隔夜持有 → T+1 收盘(Close_T+1)卖出
收益 Ret = Close_{T+1} / Close_T − 1 − 0.35%（双边摩擦）

unfilled_guard（打板成交性防线）：若 T+1 开盘 ≥ Close_T × 1.095（一字/近一字开盘）， 说明 T 日封板极强、散户通道根本排不进单 → 该样本标记 UNFILLED 不计入可成交样本。 这是"打板没买到的代理变量"，不是"次日开盘买入"假设。

这条口径曾因代码注释与实现不符引发过一轮认知混乱，现已修复并通过历史账本逐笔审计 （见《数据洁净度审计》篇）。
