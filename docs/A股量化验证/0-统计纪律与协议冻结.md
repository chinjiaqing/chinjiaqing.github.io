# 0. 统计纪律与协议冻结

> 本系列所有结论的可信度，全部押在这套纪律上。先读这篇，再读结果。

## 为什么需要预注册

一个典型的"发现"长这样：跑 20 个因子，挑出 p<0.05 的那 2 个，宣布找到了 alpha。
这不是发现，是**多重检验抽奖**——纯噪声里也能稳定抽出"显著"。

本系列的应对：**任何假设在碰数据之前，先写协议**，内容包括——

- 研究问题与方向（不许事后反转）
- 样本宇宙与过滤规则（不许跑完再补剔除）
- 统计家族与多重检验范围（不许只报好看的桶）
- Pass/FAIL 的硬门槛（不许用"看起来还行"裁决）
- 提前申报的方法学边界（自指/选择偏误、不可交易口径等）

协议冻结后，代码只实现协议、**只跑一次、不调参**。结果无论好坏如实落盘，
允许并预期 `NO_EDGE` —— **证伪一个流行叙事，和发现一个 alpha 同等有价值**。

## 四条不可协商的纪律

1. **统计单位**：以 `(event, symbol)` 对为基本单位，但显著性检验按**事件聚类**
   （cluster bootstrap）重采样——同一事件天的多只股票不是独立样本。
2. **多重检验**：FDR 只对**预注册**的桶生效（Benjamini-Hochberg, Q=0.05）。
   协议之外临时发现的桶，一律标注"未预注册，仅描述"。
3. **样本红线**：`n_events < 30` 不出裁决结论；报告永远双列 `n_events / n_pairs`。
4. **时间胶囊**：已归档的事件标题/摘要**不可 UPDATE**；证据只 append；
   合并只允许"旧吸收新"。防止"事后改写历史"。

## 未来函数防线（最难守的一条）

**媒体/公告时间戳不可信**，不能直接当"市场已知时刻"。

规则：每个事件映射一个 `available_time`——盘前公告→09:30、午间→13:00、
盘后→次日 09:30（由规则表映射，与 `rule_version` 成对保存）。
收益窗口只从 `available_time` 之后的行情起算，杜绝 look-ahead。

一句话：**采集/抽取/统计，都只能看到 ≤ as-of 时刻的信息**。

## 执行口径（曾踩坑，已钉死并审计）

Step 1/4 基准线采用**真实 A 股 T+1 跨日持仓**，不是"当日买当日卖"：

```python
# step4_forward_log.py settle() 核心（冻结口径）
ev = close_t1 / close_t - 1 - FRICTION      # close_t = T日涨停收盘价（成本）
                                             # close_t1 = T+1 收盘价（离场）
# unfilled 防线：T+1 开盘 ≥ close_t×1.095 → 反证 T 日打板排不进单 → 不计入样本
if open_t1 >= close_t * FROZEN["unfilled_open"]:   # 1.095
    r["status"] = "UNFILLED"
```

- 买入：T 日盘中首板确认时以涨停价排单（=Close_T）
- 持有：隔夜
- 卖出：T+1 收盘（Close_{T+1}），摩擦双边 0.35%
- 超额基准：中证 1000（000852）

> 该口径曾因 docstring 写成"T+1 开盘买入"引发认知混乱（A 股 T+1 制度下当日买当日卖
> 不可能），经审计确认**实现一直是对的、注释错了**。修复与审计过程见《6. 数据洁净度审计》。

## 裁决语言

| 裁决 | 含义 |
|---|---|
| `NO_EDGE` | 扣除摩擦后无可辨识的正期望（**干净的负面结论**） |
| `GATE_NO_EDGE` | 闸门/择时层无增益 |
| `有 edge（回测层）` | 回测显著为正，**不代表可交易**，需前向验证 |
| `DIP_EDGE_CONFIRMED` 等 | 理论上的通过形态（本系列尚未出现） |

**"值得研究" ≠ "该买"**。V0 阶段系统不产生任何买卖信号。
