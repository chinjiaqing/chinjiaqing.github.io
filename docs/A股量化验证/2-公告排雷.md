# 2. 公告排雷：LLM 剔除利空龙头有用吗（Step 3）

> 结论：**排雷本身无正贡献（甚至微损）** —— 🔒 已证伪
> 卷宗：`bench-step3-20260818.md`（A/B 组配对检验）

## 故事与反故事

市场叙事：龙头股一旦公告"股东大额减持/利空"，次日容易核按钮，应该在打板前**剔除**。
Step 3 验证：用 LLM 扫描信号股窗口内公告，把高危利空（L1 级：大额减持等）剔除后，
剩下的样本是否**显著更好**？

## 协议（V0.4 冻结）

- A 组 = 原始可成交样本（n=105）
- 剔除 = LLM 判定高危（L1 级利空公告，含大额减持等），上限损耗率 15%
- B 组 = 排雷后样本
- 判据：B 组 Ev(Close)/胜率/CVaR95 是否优于 A 组（配对比较，bootstrap 10,000 次）

## 实测结果（243 交易日）

| 指标 | A 组（n=105） | B 组（n=102） | 变化 |
|---|---|---|---|
| 均值 Ev(Close) | 0.0269 | 0.0257 | **−0.0011（变差）** |
| 胜率 P(Ev>0) | 0.6571 | 0.6471 | −0.0101（变差） |
| 中位数 Ev(Close) | 0.0421 | 0.0421 | 0.0000 |
| CVaR95 | −0.1054 | −0.1054 | 0.0000 |

LLM 在 105 只里挑出 3 只高危剔除（损耗 2.9%）：智能自控、风华高科、和远气体
（均为股东减持类公告）。剔除后样本**均值反而微降、胜率下降 1pp、尾部毫无改善**。

## 裁决

排雷**没有带来任何正向增量**——被 LLM 判为"高危"的那 3 只，事后看并不比其他样本更差。
在样本量有限的短线宇宙里，"用公告利空预筛龙头"这个动作的净贡献 ≈ 0 甚至为负。

**认知点**：公告级利空信息，在涨停板生态里大概率已被价格提前消化（能封板的本身就是
"无视利空"的强势票）；用 LLM 当"第二层过滤器"只是徒增损耗。

## 处置

- 排雷动作从主流程降级；Step 3 结论封存。
- 保留条件已写入协议：若未来样本扩至 n≥200 且排雷组 CVaR95 显著收窄（BH p<0.05），
  可由新协议版本重新启用——在那之前不再触碰。
