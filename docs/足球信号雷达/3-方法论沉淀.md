# 3 · 方法论沉淀

> 这一篇不写"哪个信号赚钱"，写**算赔率账时最容易算错的地方**——全是踩坑换来的、跨场景可复用的方法学。
> 状态：已沉淀（2026-08~10 实践确立），后续新线直接引用。

## 一、均值陷阱：`E[f(赔率)] ≠ f(E[赔率])`

赔率复合函数是非线性凹函数，**用"平均赔率"推期望，系统性地高估收益**。

- 实证：某信号用平均赔率测算 +11.9% 收益，**逐场实结算只有 +0.3%**——差了近 40 倍。

**纪律：一切策略验证必须逐场结算，严禁赔率均值估算。**（这条后来也支撑了 A 股侧"预注册 + 只跑一次"的协议精神。）

## 二、亚盘水位 → 概率方法学（2026-09-02 实践确立）

目标：把亚盘水位转换成与欧赔同构的隐含概率，两套视角互相校验。

四个坑与修法（每一步都有真实翻车案例）：

1. **水位是"净赢倍率"，先 +1 才是总赔率**：`总赔率 = 1 + 水位`，隐含概率 = `1 / (1 + 水位)`，再按 Σ 去抽水。
   直接拿水位取倒数会算飞。
2. **走盘/赢半必须排除出命中率分母**：平半盘的平局、半一盘的净胜 1 球都属走盘/赢半。
   不排除会校准失真——初版因此把真实主赢盘率误判虚高到 64%，修正后回到 ~48%。
3. **背离必须同口径对比**：直接算「亚盘主赢盘概率 − 欧赔主胜概率」是错误指标——让球本身就会造成 5~10pp 差异。
   只比对语义等价事件：主让半球≡主胜 / 主受让半球≡主不败 / 平半盘借平赔拆分。
4. **检验转化质量看"校准"，不看"方向命中率"**：亚盘经让球平衡后方向本就 ≈50%，命中率 ≈50% 是正常设计，不是信号失效。

顺带结论：**亚盘抽水通常 2~6%，远低于欧赔 8~12%**（单日实测 5.2% vs 8.6%）——亚盘视角更"干净"，
是校验欧赔信号质量的好镜子。单日 52 场中 35 场有亚盘缓存，14 场可同口径对照中有 7 场背离 ≥5pp → 有挖掘价值（尚未成规则）。

## 三、校准 vs 命中率：两种"准"不是一回事

- **方向命中率**回答"信号方向对不对"——但市场方向本来就是有偏的（热门方向天然命中高）；
- **校准**回答"隐含概率与真实发生频率是否一致"——这才是判断"赔率有没有被错误定价"的正确标尺。

A 股侧对应物：超额收益要对标基准指数（中证 1000），而不是看绝对涨跌——**脱离基准谈命中都是自嗨**。

## 四、欧亚同向性观测（候选过滤，未转正）

"亚盘让球受益方 = 欧赔信号受益方"记同向，反之为冲突：

| 口径 | 同向命中 | 反向（冲突）命中 | 差值 |
|---|---|---|---|
| 回测验证 | 83.0% | 62.3% | +20.7pp |
| OOS 跟踪（截至 09-20） | 83.5%（n=1978） | 63.5%（n=315） | +20.0pp |
| OOS 跟踪（截至 09-27） | 83.3%（n=2175） | 63.7%（n=333） | +19.6pp |
| OOS 跟踪（截至 09-30） | 83.7%（n=2299） | 63.3%（n=354） | +20.4pp |
| OOS 跟踪（截至 10-18） | 83.6%（n=3054） | 62.8%（n=454） | **+20.8pp** |

解读（区分证据与叙事）：
- **证据**：同向场次命中显著高于冲突场次，OOS 与回测基本重合（+20.8 vs +20.7pp），
  且随样本从 2293 场增至 3508 场差值保持稳定——这一条目前是全场最稳的统计结构；
- **叙事（推测）**：方向冲突 = 市场自己没想明白，信号可信度随之下降。
- **处置**：仅观测，未改任何信号；若维持可成候选过滤规则（规则化必须走预注册，禁止直接并入现役信号）。

## 五、"符号反转"：edge 归属必须由数据裁决，而不是由故事裁决（2026-09-07）

一个信号的计算输入被误替换（该用原始赔率处用了去水概率），造成实际触发方向与文档宣称**相反**，
而实测超额是**正的**——于是出现一个反直觉的处境：**按文档"修 bug"就等于把已验证的真 edge，
换成一个方向相反、从未验证过的规则。**

对照回测（口径对齐 OOS）的结果：

| 版本 | n | 命中率 | 超额 |
|---|---|---|---|
| 现役版（实际计算，语义=锐钱回热） | 52 | 90.4% | +15.8pp |
| 文字原意版（"修 bug"后，语义=锐钱离场） | 48 | 91.7% | +9.2pp |

**两版触发集完全不相交**（数学必然），且**两个相反方向各自为正超额**。

可复用的方法学结论：

1. **"修 bug"前先确认 edge 归属于哪一段计算。** Bug 可能是**承重的**——实现与注释不符时，
   正确动作是"核实语义 + 留证"，而不是条件反射地改代码。
2. **两个互斥方向都为正时，判别特征大概率不在"方向"，而在更高一层的"类别"。**
   本例中真正的判别结构更可能是"**两家职业盘大位移背离 + 热门区错位定价**"这一类，
   方向只是它的两个切面。把注意力锁在"哪个方向对"，会错过真正的信号。
3. **处置范式：文档勘误 + 影子轨并行取证，而不是直接改现役。**
   勘误带日期、不静默改写历史；对照信号走独立影子轨、n≥50 前不参与裁决。
4. **不要用叙事覆盖数据。** "注释说是 A 方向、实测却是 B 方向，所以一定是 B 在起作用"——
   这种推理跳过了统计检验；本例中 A、B 两个方向都有正超额，任何单方向叙事都是过度解释。

## 六、"超额"口径核对：三个容易读歪的地方（2026-09-14）

本项目所有信号都报"超额 = 命中率 − 赔率隐含概率"。一次逐行读码核对确认了口径，也查出三处容易读歪的地方。

**口径本身（已写死）**：

- 隐含概率取**去水后的公平价**（把胜/平/负三路抽水归一化后得到；双选口径 = 主+平 或 客+平）；
  各家赔率**逐场先算概率再取平均**，不是"先平均赔率再算概率"（后者正是本篇 §一"均值陷阱"的坑）；
- 用的是**临盘 latest 行情**，不是"赛前 T-15min 下注口径"——脚本里的时点取数只当过滤器用，取不到就跳过该场。

**三个必须记住的读数提醒**：

1. **基准是"去水公平价"，不是"含抽水实价"** → **超额 > 0 ≠ 可获利**。
   真金白银要过抽水这一关，超额只说明"信号比市场多知道一点"，不说明能赢钱。
2. **超额虚高的潜在瑕疵**：去水失败场次的隐含概率被按 0 计入，会把整体隐含拉低、**把超额抬虚**。
   属已知口径瑕疵，**未改动**（改动须走预注册）。
3. **可承受抽水上限**（= 命中率 / 隐含 − 1，实测推算）：VETO ≈ 20.9%、HOME ≈ 4.7%、GLOBAL ≈ 1.4%、QUAKE ≈ −2.6%。
   对照欧赔常见总抽水 5~10%——**只有 VETO 有明显余量**。
   且该门槛只针对"双选方向"，真下注要落到单腿，故它只是**必要条件、非充分条件**。

> 方法学要点：**"超额为正"和"能赚钱"之间隔着一整层抽水。**
> 任何把超额直接当成收益率的说法都是口径错误；报超额时必须同时给出基准性质（去水 / 含抽水）与样本量。

## 七、显著性检验：把"稳"和"显著"分开（2026-10-21）

一个信号跑了 1400 场、超额稳定在 +2pp，直觉会说"稳了"。
但"稳"只说明**每次读数的点估计都在那附近**，它没有回答一个更基本的问题：
**如果真实值是 0，看到 +2pp 的概率有多大？**

**方法三步**（全部可复现，固定随机种子）：

1. **二项近似算标准误与置信区间**：命中率的 SE = √(p(1−p)/n)，超额区间 = 命中区间 − 隐含概率；
2. **聚类 bootstrap**：按"日"和"联赛"两种方式重采样 1,000 次。**为什么必须做**——
   同一天、同一联赛的比赛不独立（场地/天气/裁判尺度/联赛风格/资金同源），
   把 3,000 场当 3,000 个独立观测会低估方差；
3. **设计效应** =（聚类 SE / 朴素 SE）²，用来量化"独立性假设错得有多离谱"。

结果见 [1-V5信号体系与考决](./1-V5信号体系与考决) §七。三条可复用的教训：

**教训一："接近门槛"和"显著"是两种完全不同的失败。**
一个 +2.2pp 的信号，可能"差 2.8pp 就到 5pp 门槛"，也可能"连 0 都排除不掉"。
前者是**幅度问题**（信号真实存在，只是不够大），后者是**存在问题**（还不能说它有 edge）。
报告如果只给点估计 + 门槛，读者必然把两者混为一谈——本例中两条信号拿的是同一个 ⚠️ 标签，
实际性质一个是"稳但不够大"，一个是"连存在性都没证成"。
**处置：判据档位里必须有一档叫"统计不显著"，不能把它塞进"观察"。**

**教训二："聚类一定会放大方差"是直觉，不是定理。**
此前推测"同日同联赛相关 → 聚类修正后 CI 只会更宽"。实测**错**：
设计效应只有 0.77~1.12 倍，按日聚类甚至更窄。
为什么会小于 1？当簇内存在轻微负相关时（"今天这批一起中 / 一起不中"被聚合成一个整体，
反而抵消了部分抽样波动），有效样本量会上升。
**所以这一步必须实测，不能靠推理补**——但也要留怀疑：设计效应 <1 同样可能意味着 bootstrap 低估方差，
不宜把区间读得比它看起来更窄。

**教训三：显著性不解决"能不能赚钱"。**
CI 下界 >0 只说明"比市场多知道一点"，距离"扣掉抽水还有余"还隔着一整层（见本篇 §六）。
**统计显著 ≠ 可执行**，这两件事在本系列里始终分开表述。

## 八、"多信号叠加更强"的证伪：伪叠加如何制造退化假象（2026-10-23）

**现象**：一个常用聚合指标——"两个以上信号同向（叠加组）的命中率"——
从 8 月的 ~80% 掉到 10 月的 **62.5%（45/72）**，连续多日低位。看上去像"信号体系在退化"。

**诊断（三层，全部只读）**：

| 口径 | 结果 |
|---|---|
| 08 月 叠加 vs 基线 | 78.9% vs 80.3%（−1.4pp） |
| 09 月 叠加 vs 基线 | 81.8% vs 81.6%（+0.2pp） |
| **10 月 叠加 vs 基线** | **62.5%（45/72）vs 80.6%（−18.1pp）**，Wilson 上界 72.8% 仍低于基线 → **不是抖动** |
| 全量分布 | 单信号 81.3%（2842/3495）；双信号 75.5%（197/261）；**三重及以上为零** |
| 双信号构成 | **GLOBAL+QUAKE 219 场（占 84%）/ 72.6%**；GLOBAL+VETO 37 场 / 94.6%；GLOBAL+HOME 3 场；HOME+VETO 2 场 |
| **剔除 QUAKE 共现后** | **10 月 80.0%（8/10）vs 基线 80.6% —— 几乎完全一致** |

**结论分两层，必须分开说**：

1. **"10 月叠加崩盘"是假象，成因是共现污染。** 10 月 GLOBAL 自身在退坡（见 §七），
   而 **84% 的"叠加"其实是 GLOBAL + 它自己的弱子集**——于是 GLOBAL 的下滑被完整记到了"叠加"头上。
   剔除这个污染后，10 月与基线几乎一致。**体系没有退化，是指标被污染了。**
2. **但"多信号叠加 = 更强"这个假设，在全量口径下本来就不成立。**
   75.5% < 单信号 81.3%——**叠加组的命中率比单信号还低**。
   原因同上一段：84% 的叠加是**伪叠加**（同一条信息被计价两次、贴两个标签，看起来像"两个信号都同意"）。
   真正有信息量的只有 **GLOBAL+VETO（94.6%，n=37）**，样本偏小，不足以下结论。

**可复用的方法学（三条）**：

- **指标退化时，先拆构成，再谈退化。** 聚合指标的异常，往往来自某个子集的**占比变化**，
  而不是整体真的变差了。拆开看之前，任何"体系退化"的叙事都是猜。
- **"样本量"可以被口径制造出来。** 一个信号显示 n=33（"样本不足，继续攒"），
  它的真实触发可能是 246 场——差别全在"是否允许与其他信号共现"。
  **看 n 之前先问一句：这个 n 数的是什么？** 只算独占与允许共现，能差出一个数量级。
- **同源信号不能当独立证据叠加。** 如果一个信号是另一个的子集，它们的"共现"不提供额外信息，
  只会制造一个好看的"互相确认"叙事。**独立性是叠加的前提，而独立性要靠触发集是否相交来验证，不能靠名字。**

> 处置（**未执行**）：建议叠加统计排除该弱子集的共现，或把"叠加"重定义为
> "**不同方向的独立信号共现**"。两种都属口径变更，须用户拍板 + 留卷宗。

## 九、可复用的纪律清单（跨 A 股 / 足球通用）

1. 结论必须带 **n（样本）与口径与日期**；样本不足只描述不裁决；
2. 区分 **证据（实测）** 与 **叙事（机理推测）**，叙事不作结论引用；
3. 同一段历史挖参数 = 过拟合；规则冻结后不再调阈值；
4. 验证看 **OOS / 逐场实结算 / 校准**，不看回测均值、不看方向命中率、不看"看着很赚"的叙事；
5. 扣除真实摩擦（A 股双边佣金印花、足球抽水）之后再谈 edge；
6. **判准必须在看到结果之前写死**：事后按结果挑判准（"用或还是且""要不要放宽停机"）= 判准 shopping，属 p-hacking；
7. **实现与注释打架时，先查 edge 归属再决定改不改**：Bug 可能是承重的（见本篇 §五）；
8. **报"超额"必须同时交代基准性质与样本量**：去水公平价基准下的超额为正 ≠ 可获利，两者之间隔着抽水（见本篇 §六）；
9. **"到线"不等于"更好"**：信号走完判据线后，样本继续增加往往伴随超额向均值回归——
   要如实记录退潮，而不是把"到线那一刻"当作永久结论。
10. **对账链路与展示链路是两条独立管线，谁坏了查谁**：统计侧数字正常、而公开页显示"无信号"时，
   **先怀疑展示层的关联/渲染，不要怀疑数据采集**。同理，展示层出问题不代表统计结论失效——
   两条链路必须各自有独立可验证的产出（见 [4-读盘与展示](./4-读盘与展示) §四）。
11. **报点估计必须同时给区间**：不给区间，"差一点到门槛"和"根本没证成"会被读成同一件事——
   而这两件事对"要不要继续投入"的答案完全不同（见本篇 §七）。
12. **聚合指标异常，先拆构成再谈退化**：退化的常见成因是某个子集占比变了，不是整体坏了；
   拆开之前，一切"体系退化"的叙事都只是猜（见本篇 §八）。
13. **看 n 之前先问"这个 n 数的是什么"**：允许共现与只算独占，能差出一个数量级；
   **同源信号（一个是另一个的子集）不能当独立证据叠加**，独立性要靠触发集是否相交来验证，不能靠名字（见本篇 §八）。
