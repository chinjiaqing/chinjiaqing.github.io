1 · V5 信号体系与考决 ​

状态：V5 四信号冻结后 OOS 观测中（截至 2026-10-24） 口径：命中 = 不败方向命中；超额 = 命中率 − 赔率隐含概率（去水）

一、V5 是什么 ​

老一代"裁判层"（多路亚盘/大小球/欧赔信号汇总成单一裁定）在真实回放中被证伪为负期望后（见 2-历史战线与下注层废弃）， 项目 2026-08 重建为 V5：只保留"方向级"欧赔信号——不预测比分、不猜庄家意图，只回答一个问题： 这个市场的钱在往哪边走，跟不跟。

V5 的信号全部是结构规则（由赔率轨迹的形态触发），不是机器学习——定稿后禁止在同一段历史上再挖阈值，防过拟合。

  2. 升级逻辑（概率流向 → 直接看主胜/客胜）：比赔率版低 6~7pp，且 OOS 分歧场次对旧版全错——确认负贡献，禁用。

三、冻结纪律 ​

  • 上述 4 条定稿后不再修改、不再挖阈值（同段挖参 = 自欺）；
  • 判据线：SSS_VETO 需累计 50+ 场且命中率 >70% 才谈转正；QUAKE 的两家版 vs 赔率版之争交给样本说话；
  • 真实生产 edge 应低于考决数字（考决用最终态赔率快照，与赛前实时信号存在时点漂移——08-18 实测同一场赛前/赛后重跑信号会变）。

  • VETO 的"到线后退潮"完整走完了一个来回：09-13 到线时 56 场 / 91.1% / +16.1pp → 09-27 65 场 / 87.7% / +12.3pp → 10-04 73 场 / 89.0% / +13.4pp → 10-18 88 场 / 87.5% / +12.3pp → 10-24 94 场 / 88.3% / +13.0pp。 即：回摆之后回到原点，然后围绕 +13pp 小幅震荡，样本又增加了 6 场。 → 这个"回到原点"比"单调下行"信息量更大：10-04 那次 +13.4pp 的回摆确实是噪声， 真实值就在 +12~13pp 附近，且随着样本增加并没有变好。 但"到线"只等于具备谈转正的资格，不等于转正——转正是规则/定位层面的变更，须用户裁决并留预注册卷宗；
  • QUAKE 超额连续十二日为负（33 场 / 60.6% / −0.9pp）：四条里唯一超额为负的一条。 但 10-21 的诊断改变了这个问题的性质——它根本不该被当作"样本不足待观察"来处理（见 §七）。 若按判据走到 50 场仍为负，应进入处置讨论（需用户裁决，不自动执行）。

五、VETO_H 的符号核实：一次"修 bug 会杀掉真 edge"的复盘（2026-09-07） ​

一次外部代码审查指出：定盘星背离（VETO_H）的赔率位移计算里，传入的是去水后的概率而非原始赔率， 导致实际触发语义与文档宣称方向相反。核实结论如下（脱敏，仅列方法）：

  1. Bug 属实：位移函数喂错了输入（该用原始赔率处用了去水概率），使实际计算量变成"概率的对数位移"； 因去水归一化会引入符号反转，实际 firing 语义 = 两家职业盘大位移背离下的"锐钱回热"， 与注释宣称的"锐钱离场"方向相反。

  2. 但"修复"会杀掉唯一真 edge：按注释原意做对照回测（口径对齐 OOS），

    版本n命中率超额
    现役版（实际计算）5290.4%+15.8pp
    文字原意版（"修 bug"后）4891.7%+9.2pp

    两版触发集完全不相交（数学必然：同一腿的 logP 降 ⟺ logOdds 升），且两个相反方向各自为正超额。

  3. 处置（三条，均不改判定口径）：

    • 文档带日期勘误（不静默改写历史），并把"禁止盲目修参"写成代码注释；
    • 摘除已处死的展示层方向标签（升级逻辑早在 08-21 考决被判负贡献，纯显示层，不进入统计）；
    • 建独立影子轨并行取证——"文字原意版"作为对照信号持续记账，n≥50 前不参与任何裁决。

这条的价值不在"抓到一个 bug"，而在暴露了一种更危险的冲动：看到实现与注释不符就条件反射地"修"。 当实测 edge 归属于带 Bug 的实际计算时，Bug 是承重的——修掉它等于换了一个从未验证过的方向。 真正的判别特征也许根本不是"方向"，而是"两家职业盘大位移背离 + 热门区错位定价"这一类结构， 方向只是它的两个切面。edge 归属必须由数据裁决，不能由故事裁决。

七、统计显著性：把"稳"和"显著"分开（2026-10-21） ​

到 10-18 为止，四信号的读数看上去是"两条大的稳、一条强的回落、一条小的转负"。 但"稳"是一个叙事，不是检验结果。10-21 做了一轮完整的显著性检验，结论比数字本身更重要。

方法：全量口径下按二项近似算标准误；再用聚类 bootstrap（按日 / 按联赛，1000 次重采样，固定种子可复现） 检验"同日同联赛的相关性"会不会改变结论。样本基数：有效信号场 3,692（10-21 口径）。

信号超额朴素 95% CI按日聚类 CI按联赛聚类 CI判定
SSS_VETO+13.0pp[+6.4, +19.6][+7.2, +19.1][+5.8, +19.6]✅ 统计显著，两条路径下界均 >5pp

这张表推翻了三个此前的读法：

  1. "GLOBAL 差 1.5pp 就到 5pp 门槛"是错的。 它的区间跨 0，且三个月逐月都跨 0 （08 月 [−1.1, +6.3]、09 月 [−0.9, +5.7]、10 月 [−3.7, +5.2]）。 10 月那个 +0.8pp 不是"退坡"，而是同一状态的延续。 正确表述是：尚未证实它有 edge——这和"有 edge 但不够大"是两件事，而报告里两者用的是同一个 ⚠️ 标签。
  2. VETO 的显著性是真的。 全量 +13.0pp、10 月 +14.3pp（CI [+2.1, +26.6]）都排除 0； 9 月那个 +7.5pp 跨 0，属 n=26 的小样本噪声，不构成"衰减"的证据。 但要留一句：按联赛聚类的下界是 +5.8pp，距 5pp 线只有 0.8pp 缓冲——不宜当定论。
  3. HOME 是唯一"稳定但不达标"的一条。 三个月分别 +2.8 / +4.1 / +3.1pp， 全量 CI 稳定排除 0——方向是稳的，问题只是幅度不够。

一处必须自我更正的地方：上一轮曾推测"同日同联赛存在相关性 → 聚类修正后 CI 只会更宽"。 实测是错的——设计效应只有 0.77~1.12 倍，CI 宽度基本不变，按日聚类甚至更窄。 "聚类一定会放大方差"不是定理，是直觉；这次直觉输了。 保留的怀疑：设计效应 <1 也可能说明 bootstrap 低估了方差（簇内样本小、轻微负相关），故不宜把 CI 读得比它看起来更窄。

顺带查了两个数据质量假设，都被证伪：

  • 隐含概率被"填 0"导致超额虚高：3,692 条里只有 1 条为 null（0.03%）， 剔除后四信号超额差均为 0.0pp → 无污染，上述结论不受影响。 但"缺值按 0 计"仍是一个真实脆弱点（未来赔率大面积抓取失败会静默虚增），建议改为跳过并计数，属代码改动待批；
  • "方向冲突熔断 5 场被排除在统计外"：报告措辞是"空仓避险"，但实测这 5 场仍在各信号的 n 之内—— 措辞与口径不符。剔除后影响极小（VETO +13.0→+13.4pp、GLOBAL +2.0→+2.1pp、HOME/QUAKE 不变、合并 +3.10→+3.11pp）， 故建议只改措辞、不改统计（改逻辑要重算全部历史口径）。

由此暴露一个判据档位的缺口（待用户批准）：现有报告只有"转正候选 / 观察 / 待观察"三档， 没有"统计不显著"这一档，于是 GLOBAL 和 HOME 拿到了同一个 ⚠️ 标签—— 一个"稳但不够大"，一个"连存在性都没证成"。这不是数字错了，是标签把两种不同的事说成了同一种。 本轮共提了 5 项变更提案（判据加"统计不显著"档 / 报告文件名日期口径 / 缺值处理 / 熔断措辞 / QUAKE 归属）， 全部未应用，等用户拍板。

QUAKE 的"n=33 样本不足"是个伪问题 ​

这是本轮最反直觉的一条。QUAKE 长期显示 33/50，看上去是"样本攒得慢"。实测：

口径n命中率
真实触发（无条件）24671.1%
被其他信号吸收（不计入）213（占 86.6%）72.8%
独占触发（当前统计口径）3360.6%

根因是口径而非样本：对账脚本对每场只取首个匹配的信号，优先级顺序把 QUAKE 排在最后 → 它只统计"独占触发"的那一小撮。按这个口径，"攒到 50 场"在结构上极难达成（独占率 13.4%，近 10 天独占 0 场）。

更关键的是第二层：那 213 场被吸收的样本，100% 归给了 GLOBAL 的客向分支，与其余两信号零共现、方向冲突 0 场。 也就是说 QUAKE 的触发集只有两种形态：单独出现，或作为 GLOBAL 的一部分出现—— 它是 GLOBAL 的一个弱子集，不是一个独立信号。

而"独占子集 60.6% 反而比被吸收子集 72.8% 更差"这件事，指向一个更麻烦的结论： 表面上 71.1% 的命中率，是借了共现信号的 edge，不是 QUAKE 自己的。 独占子集三个月分段 62.5% / 58.3% / 60.0%，稳定贴在盈亏平衡线 61.5% 附近——稳定地没有 edge。

处置建议（未执行）：把 QUAKE 从"独立判据名单"降级为"GLOBAL 的弱子集"，移出判据线； 不处决（n=33 < 50，按纪律不到处决线）。这条改动会影响"四信号"这个对外说法， 属定位层面的变更，须用户裁决 + 留卷宗。 一个曾被提出又主动撤回的方案：给它单开一条"无条件影子轨"。撤回原因很直接—— 246 场里 213 场就是 GLOBAL，单开等于把同一批样本重复计价一次，会凭空制造一个看起来样本充足的假信号。

结论（截至 2026-10-24）：V5 四信号无一判死，但内部分化已经从"数字高低"升级为"性质不同"—— VETO 是唯一统计显著的（94 场 / 88.3% / +13.0pp，CI 下界约 +6pp）， 走完 50 场判据线后退潮 → 回摆 → 回到原点 → 小幅上行（56→65→73→88→94 场，+16.1→+12.3→+13.4→+12.3→+13.0pp）； HOME 稳定但不达标（2240 场 / +3.4pp，区间排除 0、上界压在 5pp）； GLOBAL 连"edge 存在"都未证成（1434 场 / +2.2pp，区间跨 0，三个月逐月跨 0）； QUAKE 已被诊断出是 GLOBAL 的弱子集（33 场 / −0.9pp，连续十二日负超额，n=33 是口径产物）。 一句话："到线之后"数字并没有变得更好；而"样本不够"这个说法，在 QUAKE 身上根本不成立。 影子轨（符号修正对照）越过 50 场线后（88 场 / 89.8% / +7.8pp）在 +6~8pp 区间震荡， 按建轨规则仍仅记账不裁决，是否收口须用户裁决并留预注册卷宗。 全部信号仍在观察期，无一转正。
